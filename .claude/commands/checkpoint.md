Lưu trạng thái cuối session làm việc:

1. Tóm tắt những gì đã làm được trong session này (files thay đổi, tính năng nào xong)
2. Cập nhật CLAUDE.md:
   - Section branch status (commit mới nhất, trạng thái)
   - Section pending tasks (đánh dấu xong / thêm task mới phát sinh)
   - Section "Đã hoạt động" nếu có flow mới chạy được
3. Ghi lại quyết định design quan trọng vào memory nếu có
4. Gợi ý bước tiếp theo cụ thể để session sau bắt đầu nhanh
